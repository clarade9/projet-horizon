2. Données collectées

2.1 Données stockées localement

Votre progression dans le jeu (affaires complétées, jauges, badges, choix) est sauvegardée dans votre navigateur via localStorage. Ces données restent sur votre appareil.

💡 Vous pouvez supprimer ces données à tout moment en vidant le cache de votre navigateur.

2.2 Données collectées lors des sessions formateur

Lors du mode formateur en direct, les données suivantes peuvent être collectées :

  • Prénom saisi lors de la connexion à une session live
  • Réponses aux questions et décisions prises dans le jeu
  • Score obtenu et temps de réponse

💡 Ces données sont transmises à notre base de données sécurisée (Supabase, hébergée en Europe — région Irlande).
